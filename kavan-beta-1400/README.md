# Kavan Beta 1400

EPO-foam trainer / motor glider with aileron, elevator, rudder and motor control. New
wings and tails are designed to fit its existing fuselage.

## Published specifications

| | Value |
|---|---|
| Wingspan | 1400 mm |
| Length | 966 mm |
| Wing area | 24.5 dm² (0.245 m²) → aspect ratio 8.0, mean chord 175 mm |
| Flying weight | 700–770 g → wing loading ≈ 2.9–3.1 kg/m² |
| Motor / prop | C2814-1400 brushless, 7×6" folding prop |
| ESC | 20 A |
| Battery | 3S 11.1 V LiPo, 1600 mAh (up to 2200 mAh) |
| Servos | 4 × GO-09 (9 g) |

Sources: [kavanrc.com](https://www.kavanrc.com/en/item/kavan-beta-1400-rtf-red-151588),
[air-rc.com](https://www.air-rc.com/aircraft/kavan_beta-1400_kav02-8085).
